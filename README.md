<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/TrainStatusFinder/raw/main/assets/icons/icon.png" width="35"/> Train Status Finder</h1>

<p align="center">
  Track Indian trains in real time with accurate updates on train running status, schedules, delays, platform information, and cancellations. 
</p>

## <img src="https://github.com/KrishBharadwaj5678/TrainStatusFinder/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature                | Description                                            |
| ---------------------- | ------------------------------------------------------ |
| 🚆 Live Train Status   | Track real-time train location and running status      |
| ⏱️ Delay Information   | Get updates on train delays and expected arrival times |
| ❌ Cancellation Updates | Stay informed about cancelled trains                   |
| 📅 Schedule Details    | View complete train schedules                          |
| ⚡ Fast & Responsive    | Instant updates with a smooth user experience          |
| 🌐 Web-Based           | Accessible from any device via browser                 |

## <img src="https://github.com/KrishBharadwaj5678/TrainStatusFinder/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/TrainStatusFinder.git
```

### 2️⃣ Navigate to the Project

```bash
cd TrainStatusFinder
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the App

```bash
streamlit run app.py
```
