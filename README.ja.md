<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/TrainStatusFinder/raw/main/assets/icons/icon.png" width="35"/> Train Status Finder</h1>

<p align="center">
  インドの列車をリアルタイムで追跡し、列車の運行状況、時刻表、遅延、プラットフォーム情報、運休などを正確に確認できます。
</p>

## <img src="https://github.com/KrishBharadwaj5678/TrainStatusFinder/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能              | 説明                     |
| --------------- | ---------------------- |
| 🚆 リアルタイム列車運行状況 | 列車の現在位置と運行状況をリアルタイムで追跡 |
| ⏱️ 遅延情報         | 列車の遅延状況と予想到着時刻を確認      |
| ❌ 運休情報          | 運休となった列車の最新情報を確認       |
| 📅 時刻表          | 列車の詳細な時刻表を表示           |
| ⚡ 高速・レスポンシブ     | 素早い更新とスムーズなユーザー体験      |
| 🌐 Webベース       | ブラウザからあらゆるデバイスで利用可能    |

## <img src="https://github.com/KrishBharadwaj5678/TrainStatusFinder/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/TrainStatusFinder.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd TrainStatusFinder
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリを起動

```bash
streamlit run app.py
```
