<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/TrainStatusFinder/raw/main/assets/icons/icon.png" width="35"/> Train Status Finder</h1>

<p align="center">
  Acompanhe os trens indianos em tempo real com informações precisas sobre a localização, o status de circulação, horários, atrasos, plataformas e cancelamentos.
</p>

## <img src="https://github.com/KrishBharadwaj5678/TrainStatusFinder/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade                  | Descrição                                                              |
| ------------------------------- | ---------------------------------------------------------------------- |
| 🚆 Status do Trem em Tempo Real | Acompanhe a localização e o status de circulação do trem em tempo real |
| ⏱️ Informações sobre Atrasos    | Receba atualizações sobre atrasos e horários previstos de chegada      |
| ❌ Atualizações de Cancelamentos | Fique informado sobre trens cancelados                                 |
| 📅 Detalhes dos Horários        | Consulte os horários completos dos trens                               |
| ⚡ Rápido e Responsivo           | Atualizações instantâneas e uma experiência de utilização fluida       |
| 🌐 Baseado na Web               | Acesse de qualquer dispositivo através do navegador                    |

## <img src="https://github.com/KrishBharadwaj5678/TrainStatusFinder/raw/main/assets/readme/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/TrainStatusFinder.git
```

### 2️⃣ Acesse o Diretório do Projeto

```bash
cd TrainStatusFinder
```

### 3️⃣ Instale as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Execute o Aplicativo

```bash
streamlit run app.py
```
